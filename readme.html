✈️ WxFlight Planner

Weather & Flight Mission Planning System

Version 1.0 Single HTML File No Installation Required Works Offline (HRRR tab)

📋 Overview

WxFlight Planner is a self-contained, browser-based weather planning tool designed for field campaign mission planning. It combines three key capabilities in a single HTML file:

🌤️ HRRR Forecast

24-hour point forecasts with temperature, humidity, wind, precipitation, cloud ceiling, visibility, smoke, dust, and aerosol optical depth.

✈️ Aviation Weather

Live METAR and TAF data from aviationweather.gov API with decoded fields and flight category.

🌀 Tropical Tidbits

Direct links to HRRR model maps with configurable region, variable, runtime, and forecast hour.

📥 Data Export

Download forecast data as CSV, JSON, or a composite PNG image of all charts.

🚀 Quick Start

Option A: Open Locally (Simplest)

  1. Save WxFlight_Planner.html to your computer
  2. Double-click to open in any modern browser (Chrome, Edge, Firefox)
  3. Start using immediately — no installation needed

Option B: Access via Hosted URL (Full Features)

If a hosted version is available, simply open the shared URL in your browser. All features including live Aviation API data will work.

💡 Tip: For the best experience with all features working (including live METAR/TAF), use a hosted version rather than opening locally. See the "Hosting" section below.

📖 User Guide

Tab 1: 🌤️ HRRR Forecast

  1. Select a location:
    • 🌲 DOE Bankhead National Forest (Alabama)
    • 🏜️ DustieAim – Phoenix, AZ
    • 📌 Custom (enter your own lat/lon)
  2. Set parameters:
    • Run Date (UTC)
    • Model Cycle (00Z, 06Z, 12Z, or 18Z)
    • Forecast Hours (1–48)
  3. Click "🚀 Run HRRR Forecast"
  4. View results: Summary metrics + 8 forecast charts
  5. Download: Click CSV, JSON, or PNG buttons

Tab 2: ✈️ Aviation Weather

  1. Select or type a station ID (4-letter ICAO code)
  2. Choose data type: METAR+TAF, METAR only, or TAF only
  3. Set hours back for METAR history (1–12h)
  4. Click "✈️ Get Aviation Weather"
  5. View decoded METAR observation and TAF forecast periods

Tab 3: 🌀 Tropical Tidbits

  1. Set Runtime: Date and hour (UTC) of the HRRR model run
  2. Select Region: SE US, SW US, CONUS, etc.
  3. Select Variable: Reflectivity, Temperature, Wind, Smoke, Dust, AOD, etc.
  4. Select Forecast Hour: f00–f48
  5. Click the orange link to open the map on Tropical Tidbits in a new tab
  6. Use ◀▶ buttons to step through hours, or "Animate" to auto-play

⚙️ Technical Details

Architecture

  • Single file: Everything (HTML, CSS, JavaScript) in one .html file
  • No build step: No npm, webpack, or compilation needed
  • No backend: Runs entirely in the browser
  • External dependencies: Chart.js (loaded from CDN), Google Fonts (optional)

🔧 Troubleshooting

Charts don't appear

  • Ensure you have internet access (Chart.js loads from CDN on first use)
  • Try a different browser (Chrome recommended)
  • Check browser console (F12) for errors

Aviation data shows CORS error

  • This happens when opening the file directly (file:// protocol)
  • Solution: Host the file on any web server, or use the provided link to open aviationweather.gov directly

Tropical Tidbits link doesn't open

  • Ensure the runtime date/hour is recent (within the last 24 hours)
  • HRRR data is typically available ~2 hours after the model run time
  • Try right-click → "Open in new tab" if left-click is blocked by the embedding environment

Download buttons don't work

  • Run the HRRR forecast first (data must be generated before export)
  • Some embedded environments (iframes) may block downloads — try opening the HTML file directly in a browser tab
